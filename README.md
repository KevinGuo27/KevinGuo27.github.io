# Personal Website - Kaicheng (Kevin) Guo

A personal website built with Next.js (static export) and deployed on GitHub Pages:
https://kevinguo27.github.io/

## 📁 Project Structure

- `app/page.tsx` - All page content (profile, publications, research, experience, ...)
- `app/layout.tsx` - Page title, description and font
- `app/sitemap.ts` - Generates `sitemap.xml`
- `components/ui/` - Card, Button and Badge components
- `public/` - Static files served at the site root (images, PDFs, `robots.txt`, Google verification) - **must be committed**
- `.github/workflows/deploy.yml` - Builds the site and publishes it to GitHub Pages on every push to `main`

`out/` and `.next/` are build output - regenerated by `npm run build` and ignored by git.

## 🔧 Local Development

```bash
npm install     # install dependencies (first time only)
npm run dev     # start the dev server at http://localhost:3000
npm run build   # production build into out/
```

## 🚀 Deploying

```bash
./deploy.sh
```

This builds the site locally to catch errors, then commits and pushes to `main`.
Or do it manually: `git add . && git commit -m "Your message" && git push origin main`.

## 📝 Common Tasks

All content lives in the data arrays at the top of `app/page.tsx`:

- **Publications** - edit `PUBLICATIONS`
- **Research projects** - edit `RESEARCH` (set `image2` to show two images side by side)
- **Experience / Teaching** - edit `EXPERIENCE` / `TEACHING`
- **Skills & hobbies** - edit `SKILLS` / `HOBBIES`

To add an image or PDF, copy it into `public/` and reference it as `/filename.jpg`.

## 🚨 Troubleshooting

**Images not showing?** Make sure the file is in `public/`, committed, and referenced with a leading `/`.

**Website not updating?**
- Check GitHub Actions: https://github.com/KevinGuo27/KevinGuo27.github.io/actions
- Wait 2-3 minutes for deployment to complete
- Try a hard refresh (Ctrl+F5 / Cmd+Shift+R)
